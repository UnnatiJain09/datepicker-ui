# Datepicker UI

A stylish, responsive, and interactive datepicker UI built using HTML, CSS, and JavaScript.

The project provides a custom calendar interface where users can navigate between months, select dates, view detailed date information, and explore additional date insights through a modern and animated user interface.

## ✨ Features

* Custom interactive calendar
* Navigate between previous and next months
* Select any date from the calendar
* Highlight today's date
* Selected date visualization
* Today button
* Clear selection functionality
* Date details panel
* Weekday information
* Days remaining from today
* Week number calculation
* Day-of-year calculation
* Upcoming / Past / Today status
* Dynamic date insights
* Dark mode
* Light / dark theme persistence using localStorage
* Smooth animations and transitions
* Hover micro-interactions
* Responsive design
* Mobile-friendly interface
* Keyboard-friendly buttons
* Visible focus states
* Reduced-motion support
